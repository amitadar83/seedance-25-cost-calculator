# Frame / Five

Frame / Five is a public, independent comparison of five-second AI-video costs across subscription platforms and Seedance 2.5 API endpoints.

[Open the calculator](https://amitadar83.github.io/seedance-25-cost-calculator/)

## What is included

- Monthly plan and credit comparisons for nine creative platforms.
- Pay-as-you-go comparisons for seven Seedance 2.5 API providers.
- Separate native-model reference costs where a Seedance comparison is unavailable.
- Directional sentiment themes from linked public review and community sources.
- Current, date-unknown, and archived AI-video promotions.
- Hourly official-source checks with validation and last-known-good fallback.

## Public-data and privacy policy

The site has no accounts, analytics, application cookies, advertising pixels, or form submissions. Calculator inputs stay in the browser and are not stored or transmitted by Frame / Five. GitHub Pages and any linked third-party sites operate under their own privacy policies.

Public sentiment summaries are original theme-level paraphrases. They contain no copied review text, reviewer usernames, or individual profiles. Source availability describes the evidence set; it is not a representative satisfaction score.

## Method limits

Pricing can vary by region, tax, account, checkout eligibility, model mode, resolution, duration, audio, and reference inputs. Confirm the provider's displayed debit and terms before purchasing or generating. Automated checks can retain a previous validated value when an official source is unavailable or changes beyond the review threshold.

This project is independent and unaffiliated with the listed providers. Product and company names remain the property of their respective owners.
